# M1 acceptance record

M1, the authentic map slice, was accepted on 2026-08-22. The checks below use synthetic fixtures in
CI and an uncommitted, user-owned GOG SMACX 2.0 installation for local integration. No proprietary
assets or generated screenshots are stored in the repository.

## Requirement evidence

| Requirement | Repository evidence | Acceptance evidence |
|---|---|---|
| Indexed authentic rendering | `pcx.cpp`, declarative `atlas.hpp`, and `sdl_main.cpp` preserve palettes, apply per-atlas transparent indices, cache SDL textures, and compose the terrain layers. | A real `xplanet.MP` screenshot was rendered and visually inspected on Apple Silicon; a non-empty real-map screenshot was also produced by the x86-64 Linux Release build. |
| Contour elevation rendering | `map_geometry.cpp` converts detailed contours into a continuous five-vertex ground mesh with smooth normals, sea-level coasts, planar water, and elevated picking. The SDL client applies GLSMAC-inspired lighting and water-depth treatment. | Synthetic tests cover elevation, shared corners, wrapping, coast clamping, normals, raised picking, slope lighting, ocean depth, fog, and sprite anchoring. A real `xplanet.MP` altitude screenshot was inspected on Apple Silicon. |
| Complete M1 map fields | `terran_map.cpp` retains the known 44-byte tile fields and converts altitude, climate, rockiness, fungus, rivers, resources, improvements, landmarks, and ownership into owned state. | `smac-tool verify-data` and real-map rendering completed for the exact baseline installation. |
| Projection and interaction | `map_geometry.cpp` owns projection, exact diamond picking, horizontal seam handling, polar bounds, and viewport culling. The SDL client converts high-density input to renderer coordinates. | Unit tests exercise picking at every supported zoom, seam visibility, topology, and polar boundaries. |
| Faithful movement slice | `game_state.cpp` models chassis, domains, allowances, terrain and network costs, ZOC, occupancy, transport, embarkation, and turn refresh. The client previews separately, submits commands, and animates returned events. | Unit tests cover the individual rules. The real-map acceptance command previewed and moved unit 1 from `(40,40)` to `(41,39)`, rejected an illegal non-adjacent move, and restored 3 MP on turn 2. |
| Rendering regression | The synthetic screenshot path builds indexed atlases, renders land, water, fungus, fog, and a native unit, validates representative pixels, and saves the frame. | `smac_native_screenshot` passes under SDL's software renderer in macOS and Linux CI. |
| Full-map performance | Textures are created once, terrain geometry is cached, only visible tiles are composed, and the benchmark reports median, p95, and maximum frame times against a 33.333 ms M1 p95 budget. | Apple Silicon Debug with altitude rendering, 120 frames: median 8.845 ms, p95 9.294 ms, maximum 9.551 ms. |

## Reproduction

Set `DATA_DIR` below to a user-owned extracted SMACX installation. The normal local gate is:

```sh
cmake --preset dev -DSMAC_FETCH_DEPENDENCIES=ON
cmake --build --preset dev --target format-check
cmake --build --preset dev
ctest --preset dev --output-on-failure
./build/dev/smac-tool verify-data --data-dir "$DATA_DIR"
./build/dev/smac-native --data-dir "$DATA_DIR" --acceptance-check
./build/dev/smac-native --data-dir "$DATA_DIR" --screenshot /tmp/xplanet.bmp
./build/dev/smac-native --data-dir "$DATA_DIR" --benchmark-frames 120
```

The sanitizer gate is:

```sh
cmake --preset asan
cmake --build --preset asan
ctest --preset asan --output-on-failure
```

The x86-64 Linux acceptance used Ubuntu 24.04, GCC 13.3, Ninja, and the pinned fetched SDL 3.4.14,
SDL_image 3.4.4, and SDL_ttf 3.2.2 dependencies. It performed a clean Release configure/build,
ran all CTest tests through SDL's dummy/software renderer, verified the real asset directory and
baseline executable identity, ran `--acceptance-check`, rendered a real screenshot, and asserted
that its output file was non-empty. The container ran with `linux/amd64`, so configuration reported
`Target CPU Architecture - X64` and all project binaries executed as x86-64 Linux programs.
